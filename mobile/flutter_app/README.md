# Flutter client
Run `flutter create flutter_app` from the `mobile` folder, then copy this included `lib/main.dart` over `flutter_app/lib/main.dart`. In that project run `flutter pub add http file_picker`.

Android emulator API URL: `http://10.0.2.2:8000`. Physical phone: use your computer's LAN IP and keep both devices on the same trusted Wi-Fi. Use HTTPS for deployment.
